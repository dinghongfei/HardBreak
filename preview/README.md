# 休息窗文案预览

用来核对 `src/locales.js` 里休息窗的文案：八种语言、每条提示，以及跳过按钮、不可跳过提示、圆环和翻页时钟。页面只读这些文案，不连接计时，也不会被打进安装包。

## 打开

在项目根目录启动一个静态服务，再用浏览器打开。样式和文案来自 `../src/`，服务根目录必须是项目根目录。

```bash
python3 -m http.server
```

浏览器访问 <http://127.0.0.1:8000/preview/break.html>。

## 快捷键

左下角会显示当前语言和第几条提示。

| 按键 | 作用 |
|---|---|
| `←` `→` | 上一条 / 下一条提示，共 30 条，到头后循环 |
| `↑` `↓` | 上一种 / 下一种语言，保持当前这条提示 |
| `L` | 在「跳过」按钮和「不可跳过」提示之间切换 |
| `F` | 在圆环和翻页时钟之间切换 |
| `H` | 隐藏或显示左下角说明 |

语言顺序与 `src/locales.js` 里 `HB_LOCALES` 的书写顺序一致。新增语言后，刷新页面就会出现，不用改这个预览页。

## 不包含的文案

配置窗、托盘菜单和休息前通知不在这页上。托盘和通知在 `src-tauri/src/lib.rs` 的 `LOCALES`。
